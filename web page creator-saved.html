GLM5: The Zhipu Powerhouse

Engineered for the most demanding long-horizon agentic tasks.

Agentic Superiority

GLM5 excels in autonomous decision-making and tool invocation. With a state-of-the-art performance on benchmarks like BrowseComp (62.0) and Terminal-Bench 2.0 (56.2), it represents a significant leap in multi-step logical reasoning.

BIG PICKEL: The Stealth Contender

Coding Specialist

While shrouded in mystery, BIG PICKEL has gained a following for its high-speed performance in code refactoring and simple script creation. Some speculate it is a variant of GLM 4.6 or Claude 4.5, adapted for the OpenCode Zen platform.
